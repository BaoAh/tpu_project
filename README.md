## Get started
**Makefile**
- ```make rtl```
        Run RTL simulation.
- ```make synthesize```
        Run synthesize with Design Compiler.
- ```make syn```
         Run gate-level simulation (nWave)
- ```make power```
        Run power analyze with Primetime
